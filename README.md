# bubstack.dev

The Bubstack website: a home page, plus each app's help and privacy pages under `/<app>/`. Static HTML on GitHub
Pages, with no build step, analytics or cookies.

- `index.html`, `styles.css`: the home page, using the Bub theme's colours from `bubstack/tokens/tokens.json`.
- `renaml/`: generated by `renaml/Scripts/build-support-site.py`. Regenerate there, then copy here.
- `midi-me/`: copied from `midi-me/Site/`.
- `face-hugger/`: `index.html` is written here; `privacy.html` is generated from `face-hugger/docs/privacy.md` by `face-hugger/build-privacy.py`.

A new app gets a folder and a card on the home page. The old `zak-keown.github.io/renaml-site` and
`zak-keown.github.io/midi-me-support` sites stay up until each app ships an update that points here.
